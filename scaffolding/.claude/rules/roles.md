# Roles — Capital Project Management

## Owner / Client Side

| Role | Abbreviation | Primary Responsibility |
|------|-------------|----------------------|
| Project Sponsor | PS | FID authority, board-level accountability |
| Project Director | PD | Overall project delivery, external stakeholder lead |
| Project Manager | PM | Day-to-day execution, contractor interface |
| Engineering Manager | EM | Technical integrity, discipline oversight |
| Commercial Manager | CM | Contracts, claims, procurement strategy |
| Cost Engineer | CE | WBS/CBS, EVM, forecasting, benchmarking |
| Planner / Scheduler | PL | Integrated master schedule, critical path, look-aheads |
| HSE Manager | HSEM | Safety case, HAZOP, incident management |
| Quality Manager | QM | ITPs, inspection, handover dossiers |
| Document Controller | DC | Numbering system, transmittals, document register |
| Construction Manager | CONM | Field execution oversight, contractor site coordination |
| Commissioning Manager | COMM | Pre-commissioning, commissioning, handover |

## Discipline Engineers (Owner + Contractor)

| Discipline | When Critical |
|-----------|--------------|
| Process / Chemical | Basis of design, P&IDs, process safety |
| Pipeline | Route, linepipe spec, integrity, crossings |
| Civil / Geotechnical | Foundations, ROW, HDDs, road/river crossings |
| Structural | Above-ground structures, pipe supports, buildings |
| Mechanical / Rotating Equipment | Compressors, pumps, vessels, packages |
| Electrical | HV/LV power, earthing, area classification |
| Instrumentation & Controls | SCADA, ESD, metering, telecoms |
| Corrosion / Materials | CP design, coating spec, material selection |

## Contractor Side

| Role | Reports To (Owner) |
|------|------------------|
| EPC/EPCM Project Manager | PM |
| Package Manager (Civil / Mech / E&I) | EM / CONM |
| Site Construction Manager | CONM |
| QC Inspector | QM |
| HSE Representative | HSEM |
| Commissioning Superintendent | COMM |

## Support Functions

| Role | Engagement |
|------|-----------|
| Legal / Contracts Counsel | Claims, disputes, regulatory interfaces |
| Regulatory Liaison | Permits, authority approvals |
| Finance / Treasury | CAPEX draw, reporting to board |
| Environmental & Permitting | EIA conditions, ongoing compliance |
| Community Relations | Landowner access, stakeholder engagement |
| Independent Verifier | Technical and cost assurance audits |

## Addressing Rules for Claude

- Construction site issues → CONM, copy PM
- Technical specification changes → EM, copy relevant discipline engineer
- Change order recommendations → CM, copy CE and PM
- Schedule slippage → PL, copy PM; if critical path → also PD
- HSE incidents → HSEM immediately, copy PM and PD
- Cost forecast changes > 3% → CE, copy CM and PM
